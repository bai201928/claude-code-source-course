# FACT_A 独立盲审提示词

你正在执行 M06 的事实闸门 A。请先完整读取 `D:\agent\Claude code最新\curriculum\units\M06\fact-gate-scope.md`，然后只读取其中指定源码根目录内与问题直接相关的文件。

这是独立盲审：你不知道 Codex 的研究结论，也不应猜测作者想写什么。请从源码自行重建设置发现、来源过滤、主合并链、企业策略提供者选择、解析缓存、trust 前后环境变量应用与远程策略热更新的最小机制。

禁止修改文件，禁止读取或引用 Graphify，禁止读取 M06 的 `unit-workbook.md` 或任何草稿，禁止扩散审查到整个产品。只报告会影响事实正确性、实验设计或 Harness 配置快照契约的问题。

输出必须以以下三行开始：

```text
GATE: FACT_A
VERDICT: PASS | REVISE | BLOCK
MATERIAL_ISSUES: <number>
```

随后给出：

1. 独立确认的来源、优先级与精简调用链；
2. 三类合并/选择规则及其准确适用范围；
3. 设置缓存、快照和来源可见性的边界；
4. trust 前后环境变量及 headless 的信任语义；
5. 远程策略变化怎样进入运行态；
6. 实质问题或无法确认项。

每个实质问题必须给出源码路径、符号、理由和建议验证目标。不要报告格式偏好、理论漏洞、不会影响教材结论的边缘问题或要求本单元展开完整企业策略控制平面。
