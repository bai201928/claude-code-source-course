# JSON 修复提示词

## 任务

你收到的输入是一个审查结果，但它的 JSON 格式可能存在语法问题。你需要修复格式使其成为有效的 JSON。

## 规则

1. **只修复格式**：修复 JSON 语法错误（如缺少引号、多余逗号、未转义字符、括号不匹配等）
2. **不改变语义**：不得新增、删除或修改任何审查发现的内容
3. **不重排顺序**：保持原有字段顺序
4. **不添加内容**：不得添加原有的审查结果中没有的字段
5. **不删除内容**：保留所有原有的审查发现，即使你认为某条发现不重要

## 常见需要修复的问题

- 未转义的双引号
- 尾随逗号（trailing comma）
- 缺少闭合括号
- 字符串值中包含未转义的控制字符
- 字段名未用双引号包裹
- 使用了单引号而非双引号
- 注释（JSON不支持注释，移除之）

## 输出格式

- 只输出修复后的纯 JSON
- 不要使用 Markdown 代码围栏
- 不要输出 JSON 以外的任何文字
- 不要添加"Fixed JSON:"之类的前言
