# 项目决策记录

本文档汇总了 Claude Code CLI 源码课程工程的全部架构决策，作为 Codex 和审查流程的权威参考。

---

## 一、角色分工

| 角色 | 承担者 | 说明 |
|------|--------|------|
| 主分析、主作者、主编排、最终裁决者 | Codex（GPT-5.2 Codex） | 拥有对教材内容的最终决定权 |
| 事实审查者 | DeepSeek（Claude Code模式） | 独立审查源码事实，不得修改教材正文 |
| 初学者教学审查者 | DeepSeek（Claude Code模式） | 审查教学可理解性，不得修改教材正文 |
| 课程调整决策者 | 用户（学习者本人） | 只有用户的主观反馈才能触发课程调整 |

---

## 二、事实审查规则

### 两阶段同一会话

事实审查分为阶段A和阶段B，在同一Claude Code会话中连续执行：

- **阶段A（独立盲审）**：DeepSeek 不读取 Codex 详细结论，独立分析证据包中的入口、出口、调用链、控制流、数据流、消息流、状态所有权、生命周期、并发、取消、异常、恢复和持久化。
- **阶段B（对照审查）**：DeepSeek 读取阶段A结果，再读取 Codex 结论、源码地图、Claim 和证据索引，对每条结论输出：一致 / 遗漏 / 冲突 / 错误 / 证据不足 / 版本混淆。

### 证据补充

- 每轮事实审查最多提出一次补证申请
- 补证申请必须给出路径、符号、原因和目标结论
- 完整事实审查最多执行三次
- 三次仍无法确认的结论，正文使用 `【推断】` 标记

### 审查独立性

- DeepSeek 只能读取 Codex 复制的证据包
- DeepSeek 不得直接访问主工程、源码快照或 Codex 会话文件
- 阶段A结果落盘后不得修改

---

## 三、教学审查规则

- DeepSeek 第一遍只读取教材、学习者背景和前置知识
- 检查：函数堆砌、重大认知跳跃、图文冲突、核心代码不可独立理解
- 检查：是否解释了"为什么"、"如何运行"、"失败会怎样"
- 检查：TypeScript 前置知识是否充分、Java/Python 类比是否准确
- 检查：实验是否真正验证了正文结论
- 只有怀疑事实错误时才请求最小源码片段
- 普通问题最多复审一次，严重问题最多复审两次

---

## 四、纯JSON协议

- 所有审查结果只能输出纯JSON，不得使用Markdown代码围栏
- 不得输出前言、后记或JSON之外的自然语言
- 无效JSON自动重试两次

---

## 五、课程结构约束

- 单元总数：30～45
- 原核心主题不能删除（实现方式可调整，但主题必须覆盖）
- 每单元至少一个验证任务
- R3/R4 风险单元必须有运行实验、失败注入或反例
- TypeScript 与 Python 分别实现相同行为契约
- Java 用于类比和少量迁移实验

---

## 六、发布机制

- 阶段发布：每阶段 3～7 个单元
- 候选教材到正式教材采用原子替换
- 发布失败时保留旧文件不变
- 已发布单元原则上不改变编号
- 必须调整时，维护 redirects.json 重定向和修订记录

---

## 七、知识库

- 维护已确认知识库：术语表、双名称映射表（源码符号 ↔ 教学名称）、依赖关系
- 版本化纠错：发现错误时记录版本号、影响单元、修正内容
- 传播修正：修正一个单元后，检查并更新所有受影响的单元

---

## 八、教学轨道

### 双版本轨道

- **本地快照版本**：基于 `source-snapshot/` 中的实际泄露源码分析
- **新版公开行为**：基于官方仓库最新版本的差异对比
- 两者在教材中并行呈现，不得混淆

### 双名称映射

- 每个关键源码符号使用教学别名
- 教材正文使用教学名称，括号标注源码符号
- 维护全局 `双名称映射表`

### 稳定符号定位 + 行号辅助

- 使用稳定的符号路径定位（模块/类/方法），不依赖行号
- 行号仅作为辅助参考，随版本更新可能偏移

---

## 九、实验与验证

- 实验在隔离目录执行
- TypeScript 和 Python 分别实现行为契约
- R3/R4 单元必须有运行实验
- Mini Agent Harness 作为贯穿项目逐步构建

---

## 十、课程调整规则

- 课程调整只能依据用户的主观反馈（觉得难、觉得浅、节奏不对等）
- Codex 不得自动根据审查结果调整课程结构
- 审查结果只能影响当前单元的修正，不能改变后续单元的编排

---

## 十一、安全规则

- 源码快照 `source-snapshot/` 设为操作系统级只读
- 不得在教材、日志、JSON 或任何生成文件中回显真实凭据
- 不得自动推送到远程 Git 仓库
- Codex 使用 `workspace-write` 沙箱，不使用 `danger-full-access`
